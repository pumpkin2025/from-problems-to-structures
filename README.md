# 从问题到结构——数学专题探索

这套材料在一定程度上源于我对本科和博士阶段学习经历的反思：当学习内容被分割为数量庞大的知识点时，即使分别掌握了许多概念、公式和方法，也未必能够形成真正的理解。相反，如果能够抓住知识背后的结构，就会发现许多看似不同的内容共享相近的思想，也能看到一个结论如何从问题中产生、如何与其他知识相连，以及如何迁移到新的情境中。

基于这样的思考，我尝试从自然问题出发，通过连续小问逐步建立数学结构。每个专题通常从一个明确的问题出发，将暂时无法直接解决的目标分解为若干较小的问题，引导读者逐步获得所需的公式、方法和观察角度，最后把这些工具重新组合起来，完成专题最初提出的目标。

本项目希望帮助读者减少对题型识别和公式套用的依赖，重新练习：

- 从目标反推还缺少什么工具；
- 将复杂问题分解为可以处理的步骤；
- 理解概念、公式和方法为什么会出现；
- 观察不同知识背后共享的结构；
- 将已有结构迁移到新的问题中。

## 专题结构

每个专题通常包括以下三个部分：

- **主线探索**：通过连续小问逐步建立工具，并完成专题最初提出的目标；
- **理解结构**：汇总关键结果，说明各小问的作用，并呈现专题的整体推理结构；
- **拓展思考**：放宽假设、迁移方法，或连接到更广泛的数学和自然科学理论。

不同水平的读者可以采用不同的阅读方式。初学者可以沿主线逐步研究；熟悉相关内容的读者也可以先阅读“理解结构”，再选择性地研究主线和拓展。

## 第一册

### 从曲线到空间——坐标与向量的几何语言

第一册主要面向高中生、大学新生，以及希望重新建立数学推导能力的读者。

它从高中阶段可以理解的几何、运动和坐标问题出发，但不严格受限于传统教材的章节划分。全册包括一个新手教程和四个正式专题：

- **新手教程：一根绳子能围出多大的三角形？**  
  通过一个完整例子介绍本书如何分解问题、建立工具、组织推导并总结可迁移的结构。

- **A. 炮弹能够到达哪里？**  
  从斜抛运动出发，研究一族随发射方向变化的抛物线，并由极值、判别式和切触条件刻画可达区域及其包络线。

- **B. 怎样统一理解圆锥曲线？**  
  从焦点—准线距离关系与离心率出发，统一圆、椭圆、抛物线和双曲线；再通过坐标旋转与平移分类一般二次方程，最后借助双圆锥截线与 Dandelin 球，从空间几何中重新得到焦点、准线和双焦点性质。

- **C. 平面中的直线方程怎样推广到高维空间？**  
  从直线与平面的方向、垂直和距离问题出发，建立向量、内积、范数、投影与法向量的统一语言，并把这些结构推广到高维空间。

- **D. 怎样用向量描述空间中的旋转、面积与取向？**  
  从空间定轴转动的几何要求出发构造叉乘，研究其方向、长度与代数性质，并进一步联系有向面积、平行六面体体积和行列式。

第一册希望使读者逐渐体会到：坐标和向量是揭示几何关系与不变结构的语言。

## 后续各册预告

- **第二册：线性变换、体积与维数**  
  计划研究基、矩阵、行列式、不变子空间及线性变换的内部结构。

- **第三册：方程、数系与代数结构**  
  计划从方程求解与整数问题出发，研究复数、对称性和代数结构。

- **第四册：组合、递推与网络**  
  计划研究组合计数、递推、迭代、图与网络中的离散结构。

- **第五册：变化、累积与连续模型**  
  计划从变化率和累积量出发，进入微积分、微分方程与连续模型。

- **第六册：形状、曲面与拓扑结构**  
  计划研究曲面、测地线、连续变形及拓扑不变量。

- **第七册：数学模型与自然现象**  
  计划通过力学、天文学、光学及其他自然现象研究数学模型的建立与联系。

以上内容均为初步预告，后续可能发生较大调整。
