# 从问题到结构——数学专题探索

这是一套以自然问题为起点、通过连续小问逐步建立数学结构的探索材料。

它不是传统教材，也不是限时习题集。每个专题通常从一个明确的问题出发，将暂时无法直接解决的目标分解为若干较小的问题，引导读者逐步获得所需的公式、方法和观察角度，最后把这些工具重新组合起来，完成题目最初提出的目标。

本项目希望帮助读者减少对题型识别和公式套用的依赖，重新练习：

- 从目标反推还缺少什么工具；
- 将复杂问题分解为可以处理的步骤；
- 理解概念、公式和方法为什么会出现；
- 观察不同知识之间的联系；
- 将已有结构迁移到新的问题中。

---

## 第一册目标

第一册主要面向高中生、大学新生，以及希望重新建立数学推导能力的读者。

第一册的核心目标不是简单增加知识量，而是帮助读者重新建立：

- 从问题出发组织推导的能力；
- 将复杂目标分解为连续小问的能力；
- 从已有知识中重新构造公式与方法的能力；
- 理解基本概念之间联系的能力；
- 在几何、代数、分析和自然科学模型之间进行初步迁移的能力。

第一册中的专题通常从高中阶段可以理解的对象出发，但不严格受限于传统教材的章节划分。

第一册最终希望达到的效果是：

> 读者不仅能够得到答案，还能够解释为什么需要某个定义、公式或变换，以及它在整个推导中承担什么作用。

---

## 第二册目标

第二册主要面向已经具备一定大学数学基础的读者，尤其适合高年级本科生、研究生，以及希望建立更大数学知识地图的人。

与第一册相比，第二册中每一小问的跨度会明显增大。第一册中可能需要一个完整专题才能建立的结构，在第二册中可能只作为一个中间步骤出现。

第二册的重点不再只是重建基础推导能力，而是帮助读者：

- 识别不同数学理论之间的共同结构；
- 理解不同课程之间为什么会发生联系；
- 将抽象数学与物理、化学、生物学、计算机科学和工程问题联系起来；
- 从教材知识继续延伸到综述、论文和研究问题；
- 建立一张可以继续扩展的数学知识地图。

第二册并不试图成为各个领域的完整教材，而是希望通过问题建立理论之间的连接。

其核心目标是：

> 帮助读者从“学习一个理论”进一步走向“理解不同理论为什么会发生联系”。

---

## 两册之间的关系

第一册更关注：

```text
从具体问题出发
→ 分解目标
→ 建立工具
→ 完成推导
→ 理解基本结构
```
